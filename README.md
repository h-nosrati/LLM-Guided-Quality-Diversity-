The inverse design of magnetically responsive soft materials remains a formidable challenge due to the intrinsic coupling between magnetic and mechanical responses, which produces a highly non-convex design space where marginal parameter alterations can yield dramatically divergent morphologies. Although data-driven optimization strategies have partially addressed this complexity, the surrogate models employed in existing frameworks remain task-specific and lack the capacity for cross-domain generalization. This work introduces a framework that integrates a pretrained general-purpose language model as both a surrogate predictor and a design agent within a quality-diversity optimization architecture.
